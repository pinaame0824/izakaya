# 居酒屋「篝火」コンプライアンス設計事項

このプロジェクトにおいて、法的に遵守すべき設計事項を以下に定義します。

## 1. 個人情報保護 (Privacy)
- **プライバシーポリシーの掲示**: 全ページからアクセス可能なフッターにリンクを設置する。
- **取得データの最小化**: 予約に必要のない個人情報は取得しない。
- **同意の取得**: 予約フォーム送信時に、利用規約およびプライバシーポリシーへの同意を必須とする（チェックボックス形式）。

## 2. アルコール提供 (Alcohol)
- **年齢確認**: サイト内の適切な箇所（フッターまたは予約時）に「20歳未満の飲酒禁止」の警告文を掲示する。
- **予約時の確認**: 予約フォームにて「成人であること」の確認項目を設ける。

## 3. 消費者保護 (Consumer Protection)
- **価格表示**: 総額表示（税込価格）を基本とする。
- **キャンセルポリシー**: 予約ページにおいて、キャンセル料に関する規定を明記する。

## 4. 知的財産 (Intellectual Property)
- **著作権表示**: フッターにコピーライトを明記する。
- **外部アセット**: 使用する画像素材のライセンスを確認し、必要に応じてクレジットを表記する。
